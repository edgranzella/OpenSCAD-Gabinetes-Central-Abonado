# OpenSCAD Diseños 🚀

Este repositorio contiene los scripts y códigos fuente en **OpenSCAD** para el modelado 3D paramétrico de piezas mecánicas, gabinetes o soportes asociados a los proyectos de hardware.

## 📂 Contenido del Proyecto
* Archivos `.scad` con el diseño geométrico programado.
* El archivo `.gitignore` está configurado para excluir las exportaciones pesadas (`.stl`, `.obj`) y mantener el repositorio ligero.
